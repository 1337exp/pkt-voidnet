# pkt-voidnet

[English](README.md) · **Русский**

Небольшое самостоятельное сетевое ядро для игр: соединения, режимы доставки, устойчивость к враждебному вводу. Ничего не знает об игре, которая построена на нём.

**Статус: этап 1 готов, соединений пока нет.** Формат на проводе записан (`docs/wire.ru.md`) и реализован: разбор и построение датаграмм, окно номеров пакетов, подтверждения, детерминированный имитатор сети, цели фаззинга и тестовые векторы, которые проверяет вторая реализация на другом языке. Рукопожатие и каналы доставки следующие.

## Стек

- Ядро: Rust, по возможности `no_std`, наружу C ABI.
- Первый потребитель: игра Tee на Zig (фасад на Zig поверх ядра).
- Цели дизайна: изоляция, минимальный размер, тестирование без сети (sans-IO), слои, которые подключаются по желанию.

## Команды

```bash
cargo test --workspace                        # юнит-тесты, свойства, имитатор
cargo clippy --workspace --all-targets
zig test vectors/check.zig                    # независимый декодер на Zig против vectors/wire-v1.txt
UPDATE_VECTORS=1 cargo test -p voidnet-core --test vectors   # пересоздать векторы после изменения формата
# библиотека C ABI для Zig под Windows и проверка линковки:
cargo build -p voidnet-ffi --release --features abi --target x86_64-pc-windows-gnu
(cd tests/zig-abi && zig build run -Dtarget=x86_64-windows-gnu)
```

Для фаззинга нужен nightly и, на Windows, ASAN-рантайм Visual Studio в `PATH` (см. `spike/RESULT.md`): из `fuzz/` команда `cargo +nightly fuzz run parse_datagram`.

## Как устроено

- `docs/wire.ru.md`: единственное нормативное описание байтов. `vectors/wire-v1.txt`: строки байтов с каноничным прочтением.
- `crates/voidnet-core`: `no_std`, без выделения памяти, `forbid(unsafe_code)`, индексирование и `unwrap` запрещены линтом.
- `crates/voidnet-sim`: ГСЧ с зерном, канал с потерями (потери, дубли, перестановка, блэкаут), хеш эталонной трассы.
- `crates/voidnet-ffi`: C ABI, `unsafe` живёт только здесь.
- Проектирование и обоснования: спецификация сетевого ядра в репозитории Tee (`docs/architecture/netcore-spec.md`).

## Пока нет

- Рукопожатия, соединений, каналов доставки, RTT и таймаутов (этапы 2 и 3).
- Полного C ABI, скрипта сборки под каждую ОС и обвязок.
